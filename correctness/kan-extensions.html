Kan extensions

This page proves the laws of panproto’s three Kan extensions along a migration on tables, graphs, and trees. Delta pulls an instance back, Sigma pushes it forward by a quotient, and Pi pushes it forward by a limit. The page also proves the two adjunctions Σ⊣Δ⊣Π with their hom-set bijections, the squares that make the graph and tree forms conjugates of the table form, and the two constructions every one of them reads first: the classification of a schema into tables, relations and columns, and the entity functor a migration states between two classified schemas.

The construction itself is explained in the Explanation part; we use the notation of Shared notation and fix the objects below once, so that each block can name them.

The objects of this page

A classified schema R has a set of tables, a set of relations (edges between two tables, each with a source leg and a target leg), for each table t a set of columns col(t) (each the name of one attribute arrow from t to a value vertex), the value vertices, and the inner edges (edges leaving a value vertex). Its entity category E(R) has one object per table and one per relation and, besides identities, exactly the two legs srce​:e→src(e) and tgte​:e→tgt(e) of each relation e; no arrow leaves a table except its identity, so two legs never compose.

An instance I of R is a finite set of rows, each with a numeric id, a table t and one cell for every column of t and no other, together with a finite set of pairs (e,a,b), e a relation, a a row at src(e) and b a row at tgt(e). A cell is a value; a labelled null may stand at the top of a cell and nowhere below it. Two values are equal when their canonical bytes are equal. An instance that meets these conditions conforms to R. Otherwise its first violation is the refusal NonConforming with a row, a column (none for a table or pair violation) and a reason, found as follows. The rows are read in ascending id; a row at a vertex that is no table of R is TableOutside; otherwise the least column that is either a column of its table without a cell (MissingCell) or a cell outside its table’s columns (StrayCell) is the violation; otherwise the least column whose cell holds a labelled null below its top level is NestedLabeledNull. A pair is charged to its source row: a pair at an edge that is no relation of R is RelationOutside, and a pair whose two rows are not rows of its relation’s source and target tables is IncoherentPair; among the violating pairs the least source row comes first, a tie going to the least relation. A row’s own violation comes before a pair charged to the same or a later row. A production instance cannot hold an incoherent pair, since inserting a pair checks that its rows lie at its relation’s endpoint tables, so IncoherentPair is a refusal of the reference alone.

A homomorphism h:I→J of instances of one schema is a map of rows that keeps each row’s table, sends each pair to a pair, and has a null map under which every cell of a row equals the cell of its image; a labelled null is sent to the value it first meets in ascending row and column order, and every later occurrence must agree. Two homomorphisms are the same when their row maps are equal and they send every labelled null of the domain to equal values. A homomorphism is thus determined by its row map: every labelled null of a conforming domain stands at the top of some cell (r,α), and each homomorphism with that row map sends it to the cell of h(r) at α. A map offered as a homomorphism I→J that is none is refused with NotANaturalMap naming the least row of I that has no image, is sent to a row outside its table, has cells that are not exactly its image’s cells under the map’s null map (a labelled null the map does not list standing for itself), or is the source of a pair not sent to a pair. A pair is thus charged to its source row and competes with the other conditions by that row, so a pair violation at a row precedes a cell violation at a later one.

A functor F:S′→T between classified schemas is a map of the kept tables of S to tables of T, of the kept relations to relations of T with the endpoints the table map gives, and of each kept column (s,α) to a column F(s,α) of F(s); the kept part S′ holds the kept tables with their kept columns and the kept relations. On E(S′) it acts by the table and relation maps and sends each leg of e to the same leg of F(e); the legs compose correctly because a kept relation’s image runs between the images of its endpoints. F is surjective on attributes when every column of every table d of T is F(s,α) for some kept column of some table s with F(s)=d. The fibre of d is the ascending list of kept tables s with F(s)=d.

The graph form of an instance has a node per row, one value subtree per cell (a leaf holding the value, or a record or list subtree that folds to it), an attribute edge from the row to its cell, and an edge per pair. The encoding E reads an encodable graph back as an instance and a layout recording every id, position, decoration and subtree; the decoding D lays an instance out as a graph through a layout. The tree form of a fan-free graph with exactly one node no edge reaches is the tree read from that node.

The finite scopes

Every law below has an exhaustive differential test over a stated scope and a property differential test. The bounded family has ten migrations: (i) two tables merged with disjoint columns; (ii) two tables merged with a shared column; (iii) a column rename; (iv) a target column outside the image; (v) a target table outside the image; (vi) a relation carried to a loop across a merge of tables; (vii) a partial self relation; (viii) two columns of one table sent to one column over the alphabet {0,1,n0​,n1​} of two integers and two labelled nulls; (ix) that column merge over the four float bit patterns +0, −0 and the two quiet NaNs; and (x) an identity carrying a relation. Its objects are every labelled instance of every source and target with at most three rows per table and six in all, every subset of the possible pairs of each relation, every cell drawn from the case’s alphabet: 248,552 labelled objects, whose per-case counts are recomputed by a separate product formula. Pi is run at the product bounds 4 and 81.

The 3,918,714,467 ordered source-target pairs of the bounded family are covered through a quotient. Two labelled objects of one case and side are in one hom profile when one is carried onto the other by a permutation of the rows within each table together with a permutation of the case’s labelled-null alphabet. Each profile is represented by the image of least canonical bytes under these permutations, and its size is counted independently as the index of the representative’s stabilizer in the permutation group. The bounded family has 18,811 profiles and 19,120,495 ordered representative pairs, whose class sizes multiply out to exactly the 3,918,714,467 labelled pairs. The two blocks on the hom-set bijections prove that the quotient is exact for every observable they check.

The graph scope is the encoding spec (a table with one structured column, a table without columns and one relation, every cell one of seven forms: a constant, both null forms, a record subtree, a list subtree, a leaf holding the list the subtree folds to, and a labelled null) with every graph of at most four table nodes in four presentations, the eighteen single-site mutations of every presentation with at most two table nodes at eight sites each, five hom families, and ten graph migrations: four merges, three column cases and three relation merges. The generated cases are functors and instances drawn from a seed: up to four tables per side with up to three columns each, up to four relations, tables merged or dropped, columns merged, dropped or missed, at most three rows per table and six in all, and integer, float and labelled-null cells.

Delta is precomposition

Statement

For every functor F:S′→T between classified schemas and every instance J of T, ΔF​J is the instance of S′ with, for each kept table s and each row r of J at F(s), one copy row rs​ at s whose cell at each kept column α of s is J(r) at F(s,α), and, for each kept relation e and each pair (F(e),a,b) of J, the pair (e,asrc(e)​,btgt(e)​). Copies are made in ascending (s,r) order; the first copy of a row keeps the row’s id and every later copy takes the next id above every id of J. The provenance records each copy with its table and the row it copies. On a homomorphism h:J→J′, ΔF​h sends rs​ to h(r)s​. Delta never creates a labelled null.

Outside the domain

A J that does not conform to T is refused with NonConforming naming its first violation. When a later copy would need an id above u32::MAX, Delta refuses with RowIdsExhausted and returns nothing. Delta on a map h from J to J′ refuses first as Delta refuses on J, then as it refuses on J′, and then, when h is no homomorphism J→J′, with NotANaturalMap naming the row defined at the top of this page.

Definitions used

Classified schema, instance, conformance, functor, kept part and homomorphism, as defined at the top of this page.

Proof

  1. Each copy rs​ lies at the kept table s and holds exactly the cells at the kept columns of s, because each F(s,α) is a column of F(s) and r conforms to T, so J(r) has a cell at it. A cell is copied unchanged, so no labelled null is nested below a cell’s top level. Each pair (e,asrc(e)​,btgt(e)​) joins rows at the endpoints of e because F(e) runs from F(src(e)) to F(tgt(e)), so a lies at F(src(e)) and has a copy at src(e), and likewise b. Thus ΔF​J conforms to S′.
  2. The ids are pairwise distinct: the first copy of each row keeps that row’s id, which is distinct from every other row’s, and every later copy takes a fresh id above every id of J, each handed out once. When none is left the operation refuses before returning, so no partial instance escapes.
  3. ΔF​J is J∘F on E(S′) with the copies named by the provenance: at a table s the rows of J∘F are the rows of J at F(s), which the copies rs​ enumerate bijectively; at a relation e they are the pairs of J at F(e), which the pairs of step 1 enumerate bijectively, and the legs agree because each copied pair joins the copies of its endpoints.
  4. For a homomorphism h:J→J′, the map rs​↦h(r)s​ keeps tables; a copied cell J(r)(F(s,α)) equals J′(h(r))(F(s,α)) under the null map of h because h preserves every cell of r; a copied pair goes to the copy of the image pair, which h preserves. So ΔF​h is a homomorphism whose null map is forced by its cells. The identity of J gives rs​↦rs​, and for h′∘h the copy rs​ goes to h′(h(r))s​ either way, so ΔF​ is a functor.
  5. The refusals on a map. ΔF​h is formed from ΔF​J and ΔF​J′ and then from h, so it refuses as Delta refuses on J, then on J′, and only then checks h, naming the row of the definition. The test maps_and_their_refusals_agree_with_the_reference executes this order on every map, homomorphism or not, between the objects of the bounded family with at most one row per table and two in all, with two refusing objects per side.

Sigma is the quotient of the disjoint union

Statement

For every functor F:S′→T and every instance I of S, ΣF​I is computed from the restriction I′ of I to the kept part: each row r of I′ at s keeps its id at F(s); the pairs are the images (F(e),a,b) of the pairs (e,a,b) of I′, as a set. Each output cell (r,β) is equated with I′(r)(α) for every kept column α of r’s table with F(s,α)=β, in ascending (r,β,α) order; an output cell with no such column holds a fresh labelled null, numbered from one above the largest null of I (zero when it has none) in ascending (r,β) order. The equations generate classes over cells, labelled nulls and constants; a class is represented by its constant, else by its least labelled null. The provenance records each fresh null with its cell, and each null of I′ whose class another value represents with that value. On a homomorphism h:I→I′ of instances of S′ such that Sigma accepts both I and I′, ΣF​h sends each row to h of it, with the null map its cells force.

On the graph form, the rows of graph Sigma at a target table are the disjoint union of the rows at the tables of its fibre, and its relation edges are the separated reflection Lsep​ of the pointwise left Kan extension of the input’s entity presheaf: two elements of one relation with equal endpoints are identified, and nothing else is.

The two total extensions defined below have different domains. The table extension of an instance of S equals ΣF​ of it exactly on the instances whose every row, cell and pair lies at a kept table, column or relation, whose every cell is a value the kind of its source column admits, which give a row to no target table with a column outside the image, and on which Sigma does not clash. The graph extension of a graph over S equals, on its rows and relation edges, the presheaf left Kan extension of its entity presheaf before Lsep​, on the graphs with no node or edge outside the kept part.

Outside the domain

A non-conforming I is refused with NonConforming. Sigma then processes every equation before it draws any fresh null. When an equation joins two classes holding different constants, Sigma refuses with SigmaConstantClash naming the first such equation in ascending (r,β,α) order: its row r, its column β, the constant of the class that already holds the cells of r at the preimage columns of β before α (left), and the constant of the class of I′(r)(α) (right); no instance satisfies the equations. Only when no equation clashes are the fresh nulls numbered, and Sigma refuses with NullIdsExhausted when one would need an id above u64::MAX. On a map h from I to I′, ΣF​ refuses as Sigma refuses on I, then as it refuses on I′, and then with NotANaturalMap when h is no homomorphism.

The table extension refuses outside its domain: an element without an image with UnmappedAnchor or UnmappedEdge, a cell its column’s kind does not admit or a target table that receives a row while one of its columns is outside the image with Validation, and a clash with SigmaConstantClash. The graph extension refuses a graph with a node or edge outside the kept part with UnmappedAnchor or UnmappedEdge; on the graphs of the graph scope it refuses nothing else, since it neither solves equations nor makes cells.

Definitions used

Instance, conformance, functor, kept part, entity category and homomorphism, as defined at the top of this page. The pointwise left Kan extension of a functor P:E(S′)→Set along F has at each object d of E(T) the colimit over the comma category (F↓d): the disjoint union of the sets P(c) indexed by the pairs (c,f:F(c)→d), quotiented by joining x at (c,f) with P(u)(x) at (c′,f′) for each arrow u:c→c′ with f′∘F(u)=f. Its separated reflection Lsep​ identifies two elements of one relation object whose two legs agree. The entity presheaf of a graph over S sends each kept table to its nodes there and each kept relation to its edges there, each leg to the endpoint map. The table extension of an instance of S (production functor_extend) moves each row to the image of its table keeping its id, each pair to the image of its relation as a set, and each cell along the column map, solving the equations of Sigma and making a fresh null at each column outside the image; it validates its input and output against their schemas. The graph extension of a graph over S (production graph_extend) moves each node to the image of its anchor and each edge to the image of its label, keeping every node id, edge id and position and identifying nothing.

Proof

  1. The rows. Let d be a table of T. The arrows of E(T) into d are its identity and the legs of the relations with an endpoint at d, so the comma objects are (s,idd​) for each kept table s of the fibre of d and (e,ℓ) for each kept relation e and leg ℓ of F(e) ending at d. Each element of P(e) at (e,ℓ) is joined, along the leg u of e with F(u)=ℓ, with its endpoint at (s,idd​). No arrow of E(S′) leaves a table except its identity, so no two rows are joined. Thus the colimit at d is the disjoint union of the rows of the fibre tables, which is the row set of ΣF​I with each row keeping its id.
  2. The pairs. At a relation ρ of T the only arrows into ρ are its identity, so the comma objects are the kept relations e with F(e)=ρ and the colimit is the disjoint union of their pairs, each leg sending a pair to the class of its endpoint. Lsep​ identifies two of these elements exactly when their endpoints agree, which leaves the set of image pairs (F(e),a,b).
  3. The cells. A cell of the output is an unknown of the value side; the equations of the statement are the conditions under which the copy of r in ΔF​ΣF​I agrees with r, which is what makes the unit a homomorphism (block Sigma is left adjoint to Delta, step 1). Closing them under transitivity gives the classes, and a homomorphism out of ΣF​I must send every member of a class to one value. A class with two distinct constants thus admits no value, which is the refusal; otherwise the least choice is the class’s constant, else a labelled null shared by the class, and the class’s least labelled null is chosen so that a null of I keeps its id. A cell with no preimage column is constrained by nothing, so it is a fresh unknown. The equations are processed in a fixed order before any fresh null is drawn, so the refusal is a function of the input, and a clash, which leaves no instance at all, is reported whatever ids remain.
  4. Conformance. Each output row lies at a table of T and holds exactly the columns of that table, because each column β either has a preimage column of the row’s table, whose cell exists, or receives a fresh null. A representative is a constant or a labelled null at the top of a cell; a constant of I′ conforms, so it has no nested null. Each image pair joins rows at the endpoints of F(e). Fresh nulls are distinct from every null of I because they are numbered above them, and distinct from each other because each is handed out once.
  5. Functoriality. For h:I→I′, the row map r↦h(r) keeps tables after F and sends pairs to pairs. A cell of ΣF​I is the representative of a class whose members are cells of I and nulls; h sends each member to a member of the corresponding class of ΣF​I′, a fresh null of (r,β) to the cell of (h(r),β), so the cells agree under the forced null map. Identities and composites are kept because the row maps compose. ΣF​h is formed from ΣF​I and ΣF​I′ before h is checked, which is the stated refusal order on maps.
  6. The graph form. By steps 1 and 2, graph Sigma (decode after table Sigma after encode) has at each target table the rows of the fibre and at each relation the image pairs, which is Lsep​ of the presheaf left Kan extension of the graph’s entity presheaf; parallel edges of the input that land on one pair are identified, and rows never are. The test g_sigma_is_the_separated_reflection_of_the_reference_presheaf_sigma executes this on every whole-source graph of the graph scope’s ten migrations: the reference builds the entity category and presheaf (rel::entity_category, rel::entity_instance), the pointwise colimit (rel::presheaf_left_kan) and its reflection (rel::separated_pairs), and each of the six production graph Sigma entry points must equal the reference graph Sigma and be isomorphic, on rows and relation edges, to that reflection.
  7. The extensions. By the definitions above, on its domain the table extension keeps each row’s id at the image of its table (step 1), takes the image pairs as a set (step 2) and solves the equations of step 3; as every element lies in the kept part, restricting to it changes nothing, and as every column of a target table that receives a row is an image, no fresh null arises, so the result is ΣF​ of the input, while the domain’s conditions are exactly the absence of the three refusals. The graph extension, on a graph inside the kept part, sends the nodes at the fibre of a target table to that table one for one, which is the colimit of step 1, and the edges at the relations carried to ρ to ρ one for one with their endpoints, which is the disjoint union of step 2 before Lsep​, because it identifies nothing. The test an_extend_agrees_with_the_reference_sigma_and_its_presheaf executes both on every whole-source graph of the graph scope’s ten migrations: the table extension of the graph’s encoding must equal rel::sigma exactly and be isomorphic on rows and pairs to rel::separated_pairs, the graph extension must be isomorphic on rows and relation edges to rel::unseparated_pairs, and each must refuse exactly where its domain is left, with the variants stated.

Pi is the limit of compatible families

Statement

For every functor F:S′→T surjective on attributes, every instance I of S and every bound b, ΠF​I is computed from the restriction I′ of I to the kept part: at each table d of T with fibre s1​<⋯<sk​, one row per tuple (r1​,…,rk​) of rows of I′ at s1​,…,sk​ whose cells at the preimages of each column β of d are all equal, that common value being its cell at β (a table outside the image has the one empty tuple); at each relation ρ of T, the pair (u,v) of rows over src(ρ) and tgt(ρ) whenever, for every kept relation x with F(x)=ρ, the components of u at src(x) and of v at tgt(x) form a pair of I′ at x (every pair when no relation is carried to ρ). A row of a table whose fibre is one table keeps the id of the row it projects to; every other row takes the next id above every id of I, the image tables first by the least table of their fibre, tuples ascending, then the tables outside the image by name. The provenance records each row with its table and tuple. On a homomorphism h:I→I′ with both ΠF​I and ΠF​I′ within b, ΠF​h sends the row of a tuple to the row of the tuple of its images. Pi creates no labelled null.

Outside the domain

When F is not surjective on attributes, Pi refuses with AttributeOutsideImage naming the least table and column outside the image; no right adjoint exists there, because a column outside the image would have to range over every value. A non-conforming I is refused next, with NonConforming. Pi then checks every product against b before it hands out any id: first, at each table of T in ascending order whose fibre has two or more tables, the product of the numbers of rows of I′ at the fibre tables; then, at each relation of T in ascending order to which no kept relation is carried, the product of the numbers of rows Pi admits at its source and target tables. The first product above b is refused with ProductSizeExceeded naming the table (for a relation, its source table), the exact product and b. Only then are rows numbered, and Pi refuses with RowIdsExhausted when a fresh id would pass u32::MAX. On a map h from I to I′, ΠF​ refuses as Pi refuses on I, then as it refuses on I′, and then with NotANaturalMap when h is no homomorphism.

Definitions used

Instance, conformance, functor, surjective on attributes, fibre and homomorphism, as defined at the top of this page.

Proof

  1. At a table d the comma category (d↓F) of E has as objects the pairs (c,f:d→F(c)). The only arrow of E(T) leaving a table is its identity, so f=idd​ and F(c)=d, which makes c a kept table of the fibre (a relation’s image is a relation, never d). The objects are thus one (s,idd​) per fibre table s, and an arrow (s,idd​)→(s′,idd​) is an arrow u:s→s′ of E(S′) with F(u)=idd​, which only the identities are, so there is no arrow between two of them. A compatible family is then one row at each fibre table with no condition linking them; on the entity part it is a tuple of fibre rows. The attribute part adds that the value Π assigns to a column β of d is the value of every preimage column, so a tuple is admitted exactly when those values agree, and that value is the cell. A table outside the image has an empty fibre, whose one family is the empty tuple; it has no columns because F is surjective on attributes and every column of d is an image only if some fibre table exists.
  2. At a relation ρ the objects of (ρ↓F) are (x,idρ​) for each kept relation x with F(x)=ρ, (s,srcρ​) for each table s of the fibre of src(ρ) and (s′,tgtρ​) for each table s′ of the fibre of tgt(ρ), the last two kinds distinct even when ρ is a loop; the only arrows besides identities are the legs of each x, from (x,idρ​) to (src(x),srcρ​) and to (tgt(x),tgtρ​). A family is thus a tuple u over the source fibre, a tuple v over the target fibre and, at each x, a pair of I′ whose legs are u at src(x) and v at tgt(x); this is the stated condition, and with nothing carried every pair of tuples is a family.
  3. The result conforms to T: each row holds exactly the columns of its table (step 1 assigns each column one value), and each pair joins rows at the endpoints of ρ. Its cells are cells of I′, which conform, so no labelled null is nested and none is created.
  4. Every product is checked against b before any row is numbered, in the fixed order of the statement (a relation’s product reads the numbers of rows Pi admits at its endpoint tables, which are counted first), so a refusal leaves no partial output, ProductSizeExceeded comes before any RowIdsExhausted, and below the bound the enumeration is complete. The ids are distinct by the argument of Delta is precomposition, step 2.
  5. For a homomorphism h:I→I′ with both limits within b, the images of the components of an admitted tuple agree at every column under the null map of h, so they form an admitted tuple of ΠF​I′, and image pairs satisfy the compatibility with carried relations because h preserves pairs. The map keeps tables and is identity- and composite-preserving because it acts componentwise. ΠF​h is formed from ΠF​I and ΠF​I′ before h is checked, which is the stated refusal order on maps.

Sigma is left adjoint to Delta

Statement

For every functor F:S′→T, every instance I of S′ that Sigma accepts and every instance J of T, the unit ηI​:I→ΔF​ΣF​I sends each row r at s to its copy rs​, with each labelled null of I sent to the representative of its class; the counit εJ​:ΣF​ΔF​J→J sends each copy rs​ to r, with each fresh null of a cell (rs​,β) sent to J(r)(β). Both are homomorphisms, and the triangle identities ΔF​εJ​∘ηΔF​J​=idΔF​J​ and εΣF​I​∘ΣF​ηI​=idΣF​I​ hold, compared as homomorphisms. When Sigma clashes on I, Hom(I,ΔF​J) is empty for every J.

Outside the domain

The unit refuses as ΣF​ refuses on I (Sigma is the quotient of the disjoint union) and as ΔF​ refuses on ΣF​I; the counit refuses as ΔF​ refuses on J (Delta is precomposition) and as Sigma refuses on ΔF​J. Neither returns a partial map.

Definitions used

Instance, homomorphism and functor, as defined at the top of this page; ΣF​ and ΔF​ with their provenance, from the two blocks the statement links.

Proof

  1. The unit is a homomorphism. The copy rs​ lies at s, the table of r. Graph Kan extensions are conjugates of the table ones

Statement

For a classified schema X, a graph is encodable over X when it passes five checks in order. The first failure is NotEncodable with the least offender of the first failing pass, each pass checking its offender’s conditions in the order listed. (1) Nodes ascending: a node of the fan shape or with an out-edge of a fan kind is FanNode, and a node anchored at neither a table nor a value vertex of X is AnchorOutsideSide. (2) Edges ascending: an edge whose source or target is no node is DanglingEdge (a refusal of the reference alone, since a production graph rejects such an edge when it is built), one whose label is no relation, attribute arrow or inner edge of X is EdgeOutsideSide, and one whose endpoints are not anchored at its label’s ends is IncoherentEndpoints. (3) Two or more edges sharing label and endpoints are ParallelEdges, naming the group, ascending, whose least edge is least. (4) Table nodes ascending and, within one, its columns ascending: a column along which the node has no edge is CellAsExtraField when the node holds a field of that name and MissingCell otherwise, and one along which it has several edges is RepeatedCell with those edges. (5) Value nodes ascending: a node with several in-edges is SharedValue; one from which following the least in-edge reaches no table node is UnrootedValue; a leaf holding neither a present nor a null value is MissingValue; a node with out-edges that holds a value, or whose out-edges form neither a record (no positions, distinct column names) nor a list (all positioned, distinct positions), is InnerValueShape; and a node holding a labelled null below its top level, or a labelled null reached along an inner edge, is NestedLabeledNull.

On encodable graphs the encoding EX​ is a table and a layout, and DX​(EX​G)=G; for every conforming table T and every layout L on which the decoding succeeds (it refuses exhausted ids or positions and a constructed graph outside the encoding domain), the table of EX​(DX​(T,L)) is T. A homomorphism of encodable graphs is a map of table nodes whose encodings form a table homomorphism; E is a bijection on these hom-sets that keeps identities and composites.

For a functor F, graph Delta, Sigma and Pi are D∘XF​∘E for the table operation XF​ of Delta is precomposition, Sigma is the quotient of the disjoint union and Pi is the limit of compatible families. The output layout is chosen from the table provenance. A row node keeps its decorations when it has one source row. The contributing input cells of an output cell are the cell Delta copies, the cells of Pi’s tuple at the preimages of its column, or, for Sigma, the input cells of the same row at the kept columns the functor sends to its column. Each output cell takes the subtree of the least contributing input cell in (table, row, column) order that, once moved onto the output cell’s own arrow, hangs from that arrow’s value vertex and still folds to the output cell, else a record-free leaf; for Sigma and Pi a subtree moves forward along the functor (each inner edge to its remap, else to the inner edge of its kind and name from its moved source), and for Delta it moves back onto the source column of the copy (each inner edge to its one preimage inner edge, the move failing when there is none or several). An output relation edge takes the least recorded position of its contributing pairs’ edges, and it takes the recorded id of its contributing pair’s edge only when it has exactly one contributing pair and the kept relation e involved (the output’s own relation for Delta, the contributing pair’s for Sigma and Pi) is the only kept relation sent to F(e) and both endpoint tables of F(e) have one-table fibres. Selected ids are kept at their first occurrence when unclaimed, and every other node and edge is fresh above every input and layout id. An edge with no recorded source (the attribute edge of a fresh leaf, or a relation edge with no contributing pair) is created: at a node with an out-edge that carries a recorded position, the created out-edges take the next positions above the largest such, in ascending edge id, and elsewhere they take none. Whenever the decoded objects in the displayed hom-sets exist, their units, counits and transposes are those of the table adjunctions read through E. The resulting hom-set bijections are natural on composites for which every constituent operation is defined. An adjunction on whole graph categories additionally requires those categories to be closed under the three decoded operations; that closure is not asserted for every classified schema.

Graph provenance names, for every output node and edge, every input node and edge that contributes to it: a row its source rows, a cell’s nodes and edges every node and edge of its contributing input cells as defined above, and a relation edge the input edges of its contributing pairs.

Outside the domain

A schema-taking form refuses with RelSchema when either schema has no classification (the source first), then with Functor when the migration states no functor; every form then refuses with NotEncodable for an input outside the encoding domain, with Adjunction carrying the table operation’s refusal, and with NodeIdsExhausted, EdgeIdsExhausted or EdgePositionsExhausted when decoding has no id or position left, and finally with NotEncodable if the privately constructed output fails an encoding check. Table Kan extensions are the encodings of the graph ones

Statement

For every functor F and every conforming instance T whose record-free decoding D(T) succeeds, and for X each of Delta, Sigma and Pi: when XF​ refuses on T, the graph route gX​(D(T)) refuses with the same refusal; when XF​ accepts T and the graph route’s decoding of XF​(T) succeeds, the table of E(gX​(D(T))) is XF​(T), so the two routes agree on every observable of the table.

Outside the domain

A refusal of the table operation is the graph route’s Adjunction refusal with the same payload; a table that does not conform is refused by both with the same NonConforming reason. The graph route alone can refuse with NotEncodable when its constructed output fails an encoding check, or with NodeIdsExhausted, EdgeIdsExhausted or EdgePositionsExhausted when the decoding of XF​(T) has no id or position left. The table operation, holding no value nodes or edges, never meets those allocation refusals: along the merge of a{x} and b{x} into m{x}, one row of id u32::MAX - 2 decodes and table Delta accepts it with copies at u32::MAX - 2 and u32::MAX - 1, while graph Delta needs two more nodes for their leaves and refuses with NodeIdsExhausted.

Tree Kan extensions are the graph ones read back

Statement

For every functor F and every fan-free tree X, tree Sigma and tree Pi of X are graph Sigma and graph Pi (restricted forms) of X’s graph form, read back as a tree, and tree Delta is graph Delta read back the same way. The read-back of a graph checks, in this order and each time at its least offender: a fan node a tree cannot carry; an edge carrying a position; a node with incoming edges from two different nodes, or two edges from one node to one node; a cycle; and, among several roots, a fan spanning two of their trees. A graph that passes them is a tree when exactly one of its nodes, fan nodes set aside, has no incoming edge, and is read from that root; with no such node (the empty graph) or several, it has no tree form.

The tree-Kan domain holds the functors that are injective on tables, relations and columns, on the value vertices of the kept part (each sent to its vertex remap, else to itself) and on its inner edges, and whose image contains every target table, relation, column, value vertex and inner edge. The production tree functions relabel without building anything: tree Sigma (the extension) sends each node’s anchor to its image and each arc’s edge to its image; tree Pi, defined only for a vertex-injective map, does the same; tree Delta (the pullback) sends each node’s anchor and each arc’s edge back to its unique preimage. Each keeps every node id, the order of the arcs, the fans and the root. On the tree-Kan domain the graph form of each production tree function is identical to the graph route’s output.

Outside the domain

Tree Delta refuses a functor that sends two source vertices (kept tables, or the value vertices of kept columns, each sent to the value vertex of its image column) to one target with NonInjectiveVertexMap, naming the first collision met scanning the source vertices ascending: the least source vertex that shares its image with a lesser one, the least such lesser one, and their image, so that colliding pairs are ordered by their second source, then their first. It then refuses one that sends two source edges (kept relations, or the attribute arrows of kept columns) to one with NonInjectiveEdgeMap, naming the image (production names its endpoints). Tree Pi refuses a functor that sends two of the kept tables and the value vertices of the kept part (each value vertex sent to its vertex remap, else to itself) to one target with NonInjectiveVertexMap, naming the first collision in the same order; the production refusal names the image and its whole fibre, ascending, whose two least members are that pair. Tree Sigma refuses no merging map. A graph refusal is returned unchanged. A graph-route output that fails a read-back check is refused with NotATree, and one that passes them with other than exactly one root is refused with RootCount and the number of roots.

A migration states one entity functor

Statement

For classified schemas S and T and a migration, the entity functor keeps and maps, in this order: (1) each source table that the vertex remap maps, or that survives and is no remap image, to its remap image or itself, which must be a table of T; (2) each relation between kept tables that the edge remap maps, or that survives and is no remap image, to its remap image or to the edge of its kind and name between the endpoint images, which must be a relation of T between those images; (3) each attribute arrow of a kept table that the edge remap maps, to a target attribute arrow from the image table (ending at the value vertex’s remap when it has one), and each surviving one that is no image to the target arrow from the image table with its kind and name ending at its value vertex’s image, an unmentioned column being dropped; (4a) every edge remap is checked not to cross between relations and attribute arrows, and the remaps of inner edges and value vertices are recorded; and, for the Kan extensions, (4b) each inner-edge remap must keep the value structure: its image is an inner edge of T with the edge’s kind and name, and the schema kind of each endpoint of the image is the schema kind of the remap image of the corresponding endpoint, whether that remap image is a value vertex or a table (an endpoint without a remap keeping its own kind).

Outside the domain

Each step reports its least offender: VertexImageNotATable with the table and its image (1); IncoherentEdgeImage with the relation and its image (2, and 4a for a relation sent to an attribute arrow); IncoherentAttributeImage with the arrow and its image, or none for a surviving arrow without one (3, and 4a for an attribute arrow sent to a relation), where in step 3 the least offender is the least attribute arrow of every kept table in edge order (source, target, kind, name), not the least column name; ValueStructureRemap with the inner edge (4b). A vertex or edge survives when it lies in the surviving set, it is a remap image when some entry of the remap sends something to it, and its remap image is the target of its own remap entry, else itself.   1. Each refusal names a datum that would break this: an image that is no table leaves the object map undefined; an image relation that does not join the endpoint images breaks a leg; an attribute image that is no column of the image table leaves the cell map undefined; a remap across the divide would send an entity object to a value or the reverse.

  4. The order of the checks and the least offender within each are fixed, so the refusal is a function of the input.

Classification

Statement

For a schema and a protocol with value kinds V and non-value kinds N, the strict classification has as tables the declared tables (the vertices holding a key and the holders and targets of references) and the vertices of a kind in N; as value vertices the vertices reachable along edges from the undeclared vertices of a kind in V, the walk stopping at tables; as relations the edges between two tables; as columns of a table the edges from it to a value vertex, each named by its name, else its target; and as inner edges the edges leaving a value vertex.

Outside the domain

The first failing check is the refusal: AmbiguousKind for the least kind in both V and N; UnclassifiedKind for the least undeclared vertex whose kind is in neither; ValueReachesTable for the least edge from a value vertex to a table; DuplicateColumn for the least pair (t,c), in lexicographic order, such that two attribute arrows of the table t have the column name c.

Definitions used

Classified schema, as defined at the top of this page.

Proof

  1. Every vertex is classified exactly once: a declared vertex is a table; an undeclared one has a kind in V or in N (otherwise the second refusal), not both (otherwise the first); a kind in N makes it a table, a kind in V makes it a value vertex, and the closure adds only vertices that are not tables.
  2. An edge from a value vertex into a table would put a table inside a cell, which the third refusal excludes; so every edge out of a value vertex stays among value vertices and is an inner edge, every edge between tables is a relation, and every edge from a table to a value vertex is an attribute arrow.
  3. Two attribute arrows of one table with one column name would give a row two cells of one name, which the fourth refusal excludes, so each table’s columns are well defined.
  4. The checks run in the stated order with the least offender of each, so the refusal is a function of the input.
